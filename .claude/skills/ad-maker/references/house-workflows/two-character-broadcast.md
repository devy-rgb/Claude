How This Works
Two characters, each locked independently, occupy one static studio set that's generated once and reused as the identity
and environment reference for every still and every clip. The two characters trade lines in a real back-and-forth rhythm
rather than one person delivering a monologue, which is what makes it read as an interview instead of a single talking
head with a guest bolted on. 
Studio Set → Character Stills→ Close-Up Variants→ Locked-Camera Clips
On disclosure: if you're building anything in a dramatization or stylized-testimonial format, real, clearly-readable on-screen disclosure
text isn't optional and isn't something to minimize. This guide covers production technique only, not what claims you put in the
script. Any product claims, credentials, or endorsements in your script still need to be true and substantiated, that's on you, not on
the workflow.

Step 1, Build the Studio Set
Image model of your choice
Generate the environment empty first, before any characters. This becomes the environment reference for every still that
follows.
STUDIO SET TEMPLATE
An empty [setting, e.g. "professional broadcast news
studio"] set, photoreal. [key furniture/props, e.g. "a
modern desk, dark brushed-metal and glass finish, two empty
chairs angled slightly toward each other"].
Background: [describe the specific background elements, color
treatment, lighting style]. Camera static and level, wide
establishing framing capturing the full set.
[If your format uses on-screen graphics: describe the
graphic in full, exact text, position, colors, since a still
image renders text far more reliably than a generated video
does. This becomes the graphic's locked reference for every
later still and clip.]
Photoreal camera quality, professional lighting, shallow depth
of field, deep focus on the foreground. Vertical 9:16.
Negative: no people, no additional on-screen text beyond what's
described, no logos, no watermarks, no garbled text.

Step 2, Generate Each Character Into the Set
Image model, using the studio set as reference
Lock each character independently, using your own reference photo for identity accuracy if you have one, and the studio
set image for the environment.
CHARACTER-IN-SET TEMPLATE
Reference image provided: the empty studio set[, and a
character reference photo for identity accuracy].
ENVIRONMENT LOCK, same set exactly as the reference image: same
furniture, same background, same lighting, same on-screen
graphic if applicable, with the exact same text. Do not change
any of these elements.
CHARACTER LOCK, [describe the character: age, build,
wardrobe, distinguishing features, described at a neutral
factual level, avoid amplifier words like "stunning" or
"flawless," they push the output toward an over-beautified,
plastic look].
Place them into this set, [seated/standing position],
[close-up or wide framing]. Looking [directly into
the camera / at a slight angle toward where the other character
will sit], [expression/posture]. Camera static and
level, no motion.
Photoreal camera quality, professional lighting, shallow depth
of field, natural skin texture, no beautify filter, no AI
smoothing. Vertical 9:16.
Negative: no additional on-screen text beyond the existing
graphic, no logos, no watermarks, no change to identity or
environment beyond what's described, no garbled text.
Repeat this once per character. Generate a second close-up variant per character with their gaze angled toward the other character's side of
frame, this is what sells the "they're talking to each other" illusion once you cut between the two shots.

Step 3, Write the Script as a Real Exchange
Alternate lines between the two characters, question and answer, not one monologue with reaction shots bolted on. Split
naturally at sentence breaks, keep each clip to one beat. 
Beat Job
Open Character A frames the topic, establishing shot or straight-to-camera
Introduce Character A brings in Character B by name
Ask Character A turns the question to Character B, gaze angled toward them
Answer Character B responds, gaze angled back toward Character A
Follow-up Character A asks a natural follow-up, repeat the ask/answer rhythm
Close Character B delivers the final line
Step 4, Animate Every Clip Fully Locked Off
Video model of your choice
Camera movement is the fastest way to break this format's illusion. Every single clip locks the camera completely, restates
both the character identity and the environment from scratch, since most video models have no memory between clips.
CLIP TEMPLATE
Using the attached image as the starting frame, animate this
exact scene: [full character description, identical every
clip for that character], same [environment description,
including any on-screen graphic and its exact text], staying
exactly as shown throughout, never changing.
The camera is completely static and locked off for the full
clip, no push-ins, no pans, no zooms, no drift.
[Gaze direction: straight at camera, or angled toward the
other character], [expression/posture], and begins
speaking in [voice description: accent, tone, pacing,
identical every clip for that character], saying "[exact
line]." Mouth moves naturally in sync with every word, small
natural head movement, otherwise holds position without
repositioning.
[Ambient audio matching the setting], no music.
Keep identity, wardrobe, the environment, and any on-screen
graphic pixel-identical to the reference image the entire time,
no warping, no morphing, no flicker, no change to on-screen text
beyond what's already in frame.
Voice lock matters more than it seems like it should. Write out each character's voice descriptor once, then paste it verbatim into
every clip that character speaks in. Most video models re-solve voice fresh per clip rather than remembering it, so an unlocked
descriptor drifts noticeably by the third or fourth clip.

Step 5, Split Long Beats Before They Rush
If a single clip is carrying a dense list or a long sentence and approaches your model's duration ceiling, split it into two
clips rather than compressing the pacing. A rushed delivery reads as artificial faster than almost anything else in this
format.
