AI UGC Recreation — "5 Rules For Yapping Videos"
Full production workflow: script, character, image prompt, and Omni video prompts

1. Source & Approach
Source: an uploaded 95-second reference video ("How_to_yap.mp4"), a black-background talking-head reel titled "5 Rules for Yapping Videos To Convert," with a static on-screen list and karaoke-style captions.
The transcript wasn't available as text or audio-to-text (no speech-to-text tool was reachable in this environment), so it was reconstructed visually: frames were extracted with ffmpeg, and a median-stack composite across all frames was used to see through the moving subject and read the static on-screen title/list text underneath. Captions were read frame by frame the same way.
The recreation is a condensed, rewritten 30–32 second version, not a verbatim clone of the original spoken script; matches the format, structure, and energy in original wording. This also happens to match the source video's own closing advice: don't copy people word for word, find what's working and make it yours.
Original 5 rules (source material, for reference)
Share Stories – Connection is what we want!
Call out the nonsense – Have a stand.
Keep it unpolished – raw is better than scripted.
Need to grab attention in the first 3 seconds.
Research – Look at what topics people are actually interested in.
2. Production Decisions Locked In
Video model: Google Veo / Omni, native lip-synced voice generated directly from the dialogue in each prompt (no separate VO track).
Character: an original AI persona, not a likeness of the person in the reference video. Same raw, confident, energetic delivery style; different face, hair, and wardrobe.
Accent: confident, energetic Australian accent, locked word-for-word across every clip.
Background: seamless chroma key green backdrop (#00B140), for the user to key out and replace in their own edit.
Pose: matched to the reference video's actual framing — extreme low-angle close-up, leaning in toward the lens, one hand raised near the eyebrow mid-gesture.
One single reference image (Image 1) is reused as the starting frame for all four clips, rather than generating a unique start frame per clip.

9. Notes & Flags
Omni has no cross-clip memory: every clip resets to the same starting pose (hand near the eyebrow), so expect a small visual "snap back" at each cut. Normal for this workflow, invisible once cutting fast between clips.
Watch clip 2 in particular (25 words / 10s) for lip-sync softness, it's at the top edge of Omni's comfortable word budget.
Make sure the Notes-app list text doesn't sit where the character's head covers it for the whole clip; the original video had that exact legibility issue.
The character is an original AI persona built to avoid recreating the real creator's likeness from the reference video.
