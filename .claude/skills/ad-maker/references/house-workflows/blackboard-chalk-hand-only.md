Myoguard Pro Blackboard Chalk Ad — Seedance 2.5 Production Doc
Overview
Hand-only chalk-on-blackboard version of the Myoguard Pro whiteboard ad, no character on screen, narration is off-camera voiceover, not lip-synced
Styled after an uploaded reference video (a chalk-on-blackboard hair-loss-supplement ad): a three-color chalk system (white for headlines, pink/coral for circles and arrows, pale yellow for supporting detail), and a board-wiping transition between sections done with a black felt eraser in wide arcing strokes that leave visible ghost-smudge residue, not a perfectly clean reset
Same Myoguard Pro script as the other versions of this ad, restructured into 3 wipe-separated segments rather than one cumulative board, since this format erases and replaces content between sections instead of stacking it indefinitely
Structure: 3 clips of up to 15s each, first/last-frame anchoring between clips, voice-timbre-locked video references for narrator consistency, same core techniques as the live-action and Pixar versions of this ad
Reference Video Analysis
A 44s reference video was analyzed frame by frame before writing any prompts. Key findings that shaped this build:
Three chalk colors used consistently: white for main headlines and outlines, pink/coral for circles, arrows, and emphasis marks, pale yellow for supporting detail text
The wipe is usually partial, not a full board clear, it erases just the section being replaced while other content stays untouched
Wide arcing eraser strokes leave visible chalk-dust smudge/ghosting behind, which is what makes it read as real chalk rather than a digital effect
The ad ends by cutting to the real product with small chalk sparkle marks drawn around it

Shared Rules
CHALK COLOR RULE:
One color is used for all of that color's elements in one continuous
pass, then set down. Only after that phase is fully complete does the
hand pick up the next color, for the rest of the clip. The chalk is
never switched back and forth, and never picked back up after being
set down. (Established after an early version switched pink to white
back to pink within one clip and looked fake, batching each color
into a single continuous pass fixed it.)
 
WIPE GESTURE:
The hand sets down any chalk it's holding, picks up the black felt
eraser, and sweeps it across the board in wide arcing motions. Faint
ghost-smudge residue stays visible afterward, not a perfectly clean
reset. Kept brief and practical, not a lingering or drawn-out motion.
 
STROKE-BY-STROKE RULE:
All writing happens stroke by stroke, at a natural, unhurried
handwriting pace, ink appearing progressively as the hand moves, never
appearing instantly or as a completed word/mark before the hand has
drawn it.
 
PRONUNCIATION NOTES:
"GLP-1" is spoken as three separate letters "G, L, P" (hard P sound,
like in "pea," never a V sound) followed by "one."
"Ca-HMB" is spoken as separate letters, "C-A, H-M-B," not as a
blended word.
 
VOICE-CONTINUITY FIREWALL (Clips B and C, referencing the previous
clip's video as a voice reference):
Use the previous clip ONLY as a vocal-timbre reference: match the
narrator's voice, tone, and pacing. Do not reproduce, repeat, or
borrow any words from it, those lines are already delivered.
 
STYLE LOCK:
Real chalkboard footage, static locked camera, close-up, authentic
chalk texture and dust, no digital text or motion-graphic overlay, no
artificial blur. ASPECT: 9:16 vertical.

Troubleshooting Log
Chalk color switched back and forth within a single clip (pink, then white, then pink again) and looked fake → fixed with the CHALK COLOR RULE: one continuous pass per color, never switching back.
"GLP-1" pronounced with a V sound instead of a hard P → fixed with an explicit phonetic breakdown, same fix as the live-action and Pixar versions of this ad needed.
Clip B was generated against the wrong opening reference, and "CREATINE + CA-HMB" appeared on the board without being drawn → fixed by correcting which image was referenced as the opening frame, and adding explicit stroke-by-stroke language for that specific line.
Removed the battery shade-then-erase mechanic and the bicep icon from Clip B/C entirely, per a direct creative simplification, not a bug fix, this reduced the design to be leaner and easier to generate reliably.
Clip C: the wipe was taking too long, a checkmark appeared without being drawn, and "MYOGUARD PRO" overlapped the lines above it → three separate fixes: (1) generated a new opening frame that's already mid-wipe instead of a static finished board, since the static beat before the wipe was the real cause of the lag, (2) added explicit stroke-by-stroke language for the checkmark, (3) added an explicit LAYOUT rule giving "MYOGUARD PRO" a clear, non-overlapping position.
The wipe was still running long, so a hard numeric time cap and a letter-by-letter spelled-out drawing instruction were added for extra precision. This backfired: the next generation butchered several words in the voiceover and introduced lag between drawing and speech. The likely cause: piling on multiple mechanical, highly specific constraints in one prompt competes with the model's ability to also deliver clean, naturally-paced dialogue. Fixed by reverting to simpler language (plain stroke-by-stroke, no letter spelling, rules stated once each, more generous per-beat timing) rather than adding still more constraint text. This is the key lesson from this project: when a fix doesn't land, escalating specificity is not automatically the right next move, sometimes simplifying and giving more time per beat works better than tightening the screws further. If a clip is still too dense to render reliably even at this simpler level, splitting it into two shorter clips is the next lever, not more rules.
