# Format Module — Faceless VO + B-roll

No person on screen. A voiceover carries the whole script while stock b-roll runs
under it, word-timed captions burn over the top, and a music bed sits underneath.
The cheapest format in the engine to produce and the fastest to iterate, because
nothing about it is generated by a video model.

**Engine stack:** `tools/faceless.mjs` — local render, Kokoro TTS (or a Chatterbox
voice clone when a `refAudio` is supplied) + ffmpeg. Read
`references/faceless-video.md` (setup, jobs file, failure modes) and
`references/production-discipline.md` first. There is **no image model and no
video model in this path**, so no still prompts and no clip prompts are written.

---

## When this format fits the DNA

The competitor ad carries its persuasion in the *words* and uses picture only as
evidence or illustration — list ads ("7 things nobody tells you about…"),
mechanism explainers, price/offer breakdowns, news-hook and "here's what changed"
ads. Also the right pick whenever the DNA needs to ship in volume: 20 script
variants render locally for the cost of the transcription calls.

Do **not** pick it when the winning element is a face — a testimonial, a
confession, a reaction. That is `ugc-yapper` or `talking-head`, and those route
to Adsora Gen.

## What Stage 4 produces for this format

Three things, not prompts:

### 1. The script, verbatim and spoken-ready

The voice reads exactly what is written, so the script file *is* the deliverable.

1. **Write for the ear.** Contractions, short sentences, one idea per sentence.
2. **Spell out anything a TTS engine mangles.** Prices as "twenty nine ninety
   nine", not "$29.99". Dates as words. No symbols, no parentheses, no em dashes.
   Hunt for long word-tokens and abbreviations before shipping — they are where
   the read breaks.
3. **No accent or delivery directions in the text.** They will be read aloud.
   Voice is chosen by the `voice` field, not by prose.
4. **Segment nothing.** Unlike every other format here, the whole script is one
   continuous read; the renderer cuts picture under it, not the other way round.
5. **40–60 spoken words per 15s** is the working rate. Write to the ad length the
   DNA calls for, then check the rendered `voSec` in `manifest.json`.

### 2. The b-roll brief

The renderer draws from a folder, so the brief describes **the folder**, not
individual shots:

- 12–20 usable clips minimum, each at least 1.4s (shorter clips are skipped).
- **Screened first.** Run `tools/broll-pool.mjs` on the folder, read the
  contact sheet, drop anything with baked-in text, a watermark, a "SUBSCRIBE"
  overlay or a competitor's logo, and point the job at the resulting
  `broll-pool.json` (`brollPool`). `references/faceless-video.md` §2a.
- Vertical or croppable to 9:16 — the renderer center-crops to fill, so anything
  with action at the edges loses it.
- Name the *categories* the script needs covered (the problem state, the
  mechanism, the proof, the payoff), not a shot-by-shot list. The pack order is
  seeded, not directed.
- One optional **hook clip** per job, used as the opener and given its own
  duration (`hookSec`, default 2.6s). This is the one shot worth choosing by
  hand, because it is the only one whose placement is guaranteed.
- Music: a folder of cleared tracks. Trending songs are not licensed for paid
  ads. It rotates one bed per job.

### 3. The jobs file

A ready-to-run `jobs.json` written into `04-prompts/faceless-vo-broll.md` as a
copy-paste block and saved alongside it, with `outDir` already pointed at the run
folder's `05-assets/faceless-vo-broll/`.

```jsonc
{
  "outDir":      "./ad-remix-runs/<slug>/05-assets/faceless-vo-broll",
  "brollDir":    "~/Documents/Adsora/Video Assets Raw/B-Roll/<NICHE>",        // house library first (hard rule 16)
  "brollPool":   "./ad-remix-runs/<slug>/broll-pool.json",   // screened survivors (tools/broll-pool.mjs); beats brollDir
  "hooksDir":    "~/Documents/Adsora/Video Assets Raw/Visual hooks/<NICHE>",
  "musicDir":    "~/Documents/Adsora/Video Assets Raw/Soundtracks",                        // cleared beds only
  "voice":       "am_adam",      // house read at 1.1; af_sarah at 1.2 for female. No clone: nothing on screen to clone from
  "musicVolume": 0.06,
  "aspect":      "9:16",
  "python":      "~/.adsora/kokoro/bin/python",
  "jobs": [ { "name": "<slug>-01", "hook": "opener.mp4", "script": "<the full script>" } ]
}
```

Name jobs `<script>__<hook>` when fanning one script across several hooks — the
footage order is seeded off the job name, so the body stays identical and only
the opener changes. That is the format's A/B test.

## Production rules

1. **Voice: Kokoro preset, or a clone via `refAudio`.** Default is a Kokoro
   preset (54 voices: `af_*` American female, `am_*` American male, `bf_*`/`bm_*`
   British) — no accent prompting, so don't write accents into the script. To
   match a specific voice, add a `refAudio` (clean ~7–12s WAV) to the job or
   config and it clones zero-shot with Chatterbox. Cloning happens only where a
   `refAudio` is given; everything else stays on Kokoro. The default preset is
   the house read, `am_adam` at 1.1 (`af_sarah` at 1.2 for female): a faceless
   ad has no avatar clip to clone from, so it never clones unless the user
   hands over a reference voice (`references/house-defaults.md` §1).
2. **Captions are the written words.** Timing comes from a transcript, the text
   never does. Do not "fix" a caption by editing the script after the render —
   re-render.
3. **Three-word cues.** The default caption grouping is what social reads at
   speed. Leave it alone unless the script is unusually dense.
4. **Never stretch a clip to fit.** The packer trims footage to the voice; if the
   ad feels thin, add b-roll to the folder rather than slowing the read.
5. **Music never ducks.** Fixed gain under the voice with an in and out fade. A
   bed that fights the read was chosen too loud — lower `musicVolume`.
6. **Reruns are reproducible.** The same job name draws the same footage in the
   same order. Change the name only when a different edit is wanted.

---

## Negative constraints

There is no prompt to attach these to, so they are checks on the **script and the
folder** before the render:

- no brand names or trademarked products in the b-roll folder;
- no on-screen text in the source clips — the burned captions are the only text;
- no clip under 1.4s in the folder (silently skipped, which quietly shortens the
  pack);
- no unlicensed music, no trending-song beds;
- no claim in the script that is not substantiated in `03-rebuild.md`.

---

## Assembly note

The render is the assembly — MP4s land in `05-assets/faceless-vo-broll/` with a
`manifest.json` listing scene count, voiceover length, and any job that failed.
Nothing needs compositing afterwards except a product label, banner or end card,
if the DNA has one — add those with `tools/assemble.mjs` (`captions: false` on
that job, since the render already burned them). Check `voSec` against the target ad length before shipping the batch.
